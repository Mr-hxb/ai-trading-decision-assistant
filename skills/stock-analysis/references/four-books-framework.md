# 四书方法论框架

本文件是 `stock-analysis` Skill 的中文方法论参考。它综合以下四本书的核心思想，但不冒充原书逐字摘录：

- 《股票作手回忆录》
- 《专业投机原理》
- 《我如何从股市赚了 200 万》
- 《日本蜡烛图技术》

规则来源分为三类：

- `书籍原则`：可以清楚归属于某本书的高层方法。
- `综合推导`：把多本书组合成统一工作流的规则。
- `个人政策`：评分、风险偏好和默认参数；统一放在 `decision-policy.md`，不得伪装成原书结论。

本框架用于形成有倾向的研究判断，不构成买卖、仓位或订单指令。原书文件不是运行时输入；若需要核对具体出处，应单独记录书名、章节和版本，不得凭记忆补造页码或引文。

## 统一方法

`基本面筛选 → 市场与板块确认 → 相对强度与趋势结构 → 关键位置确认 → 风险与失效条件 → 条件化重评`

这是一套偏多头、趋势和动量风格的研究框架。除非用户明确要求其他方向，否则只评价多头 setup 的质量，不推导做空建议。

## 四本书的职责

### 《股票作手回忆录》

关注：

- 大盘和主要趋势。
- 阻力最小方向与关键位置。
- 等待市场证明，而不是频繁预测。
- 只在已有判断得到正反馈时提高关注度。
- 趋势未被破坏时，避免被普通噪声反复动摇。
- 防止过度交易、摊平亏损和情绪化重进。

### 《专业投机原理》

关注：

- 趋势的可观察定义。
- 1-2-3 趋势变化和 2B 失败突破。
- 风险回报、失效条件和纪律。
- 市场环境、宏观背景与交易假设的一致性。
- 错误时缩小暴露，而不是扩大未经证明的假设。

### 《我如何从股市赚了 200 万》

关注：

- 成长、强势和接近新高的候选标的。
- 箱体、整理区间和突破质量。
- 价格、成交量与基本面催化的共同确认。
- 突破失败只否定本次 setup，不永久否定公司。
- 止损后回到观察状态，等待新的独立证据。

### 《日本蜡烛图技术》

关注：

- 关键位置的接受、拒绝和力量变化。
- 突破、回踩、失败突破与高位加速后的确认。
- 形态之后是否出现后续验证。
- 蜡烛图只作为上下文证据，不作为脱离趋势、位置和成交量的独立预测器。

## 分析顺序

广泛的 setup、趋势或观察决策按以下顺序审查。纯行情查询、纯新闻摘要或单项数据核对可以跳过不相关步骤，并说明原因。

### 1. 市场环境

判断：

- 主要指数处于上升、下降还是震荡。
- 市场广度、成交量与风险偏好是否支持。
- 用户指定周期与市场环境是否一致。

输出 `market_regime`：`tailwind`、`neutral`、`headwind` 或 `unavailable`。

### 2. 板块与主题

判断：

- 板块相对基准是否走强。
- 是否存在多只代表性股票共同确认。
- 催化是广泛驱动还是单一个股异常。
- 关键催化是否可能已被价格充分反映。

输出板块强度、广度、确认情况和数据缺口。

### 3. 基本面与催化

判断：

- 收入、利润、现金流或关键业务指标的变化来源。
- 行业景气、竞争位置、财务质量和潜在稀释或治理风险。
- 已确认催化、市场预期和最可能证伪逻辑的事实。
- 估值或预期是否使 setup 的容错率明显降低。

基本面决定标的是否值得继续研究，不单独构成价格时点结论。

### 4. 相对强度、趋势与结构

判断：

- 个股相对大盘和板块是否更强。
- 高低点结构、箱体、前高、趋势线、2B 或 1-2-3 是否由同周期价格数据支持。
- 当前价格是否接近可观察的结构，还是已经明显延伸。
- 突破、回踩或重新收复是否存在成交量和后续价格确认。

`relative_strength` 始终表示 `relative_strength_vs_benchmark`，不是 RSI 指标。

### 5. 风险、失效与反方证据

同时记录：

- `setup_invalidation`：本次时点或价格结构何时失效。
- `trend_invalidation`：中期趋势假设何时失效。
- `thesis_invalidation`：基本面或催化逻辑何时被证伪。
- 事件、缺口、流动性、监管、估值和追高风险。
- 至少一个最强反方解释。

三类失效条件可以同时存在。不得要求用户只能选择其中一种，也不得在结果不利后临时改变原先记录的分析周期或假设。

### 6. 蜡烛图与成交量确认

只在前述趋势和关键位置已经明确时使用：

- 价格尝试突破或跌破时是否被明显拒绝。
- 收盘位置是否显示接受、犹豫或反向压力。
- 成交量是否支持该解释。
- 后续一至数根同周期 K 线是否确认。

单根锤子线、吞没、十字星或其他形态不得单独改变长期判断。

## Workflow State

`workflow_state` 与 `main_judgment` 是两个维度。状态描述研究或持仓上下文，不能自动转换成交易动作。

当数据质量被阻断或请求不适用观察状态时，使用 `unavailable`，不得为了填字段强行归类。

未持仓或普通观察场景只使用：

- `S0 excluded`：证据显示不值得继续研究，或超出能力范围。
- `S1 basic_watch`：基本面或主题值得研究，但板块和价格尚未确认。
- `S2 priority_watch`：板块、相对强度或结构开始对齐，值得重点跟踪。
- `S3 awaiting_confirmation`：接近关键结构，但仍等待明确确认或更好的风险参考。

只有用户明确提供现有持仓、既往入场或止损背景时，才允许使用：

- `S4 exploratory_position`：用户描述为试探性持仓，结构得到初步确认。
- `S5 trend_position`：用户描述已有浮盈且趋势结构继续抬高。
- `S2R post_invalidation_watch`：既往 setup 已失效，但中期逻辑尚未系统性恶化，回到条件化观察。

不得仅凭 watchlist 记录推断用户持有该标的。

## Setup 类型

以下类型只描述结构质量，不是入场命令：

### 箱体或关键前高突破

需要：

- 市场不处于明确逆风，或个股相对强度足以解释背离。
- 板块、基本面或催化至少有一项可验证支持。
- 同周期收盘、价格扩张或成交量支持突破解释。
- 重新跌回结构时有清楚的降级条件。

### 突破后的首次高质量回踩

需要：

- 突破已经得到后续正反馈。
- 回踩发生在可说明的旧阻力或新支撑附近。
- 回踩期间压力减弱，随后出现新的价格确认。
- 重新跌回原区间深处时，setup 明确降级。

### 失败突破后的重新收复

需要一条完整的重评规则，至少包括：

- 新的价格结构或重新收复证据。
- 新的确认触发。
- 新的失效条件。
- 重新评估后的风险回报。
- 基本面、板块或中期趋势没有出现新的系统性恶化。

单独出现“板块转强”“形成更高低点”或“价格反弹”等一个条件，不足以完成重评。

## 复盘原则

决策质量依据当时可获得的证据和规则执行情况评价，不能由随后涨跌倒推。

复盘至少区分：

- `rule_compliant_loss`：按规则执行但结果亏损。
- `invalidation_too_tight`：原失效条件落在正常波动内，需结合当时波动数据验证。
- `late_or_extended_setup`：分析时价格已经远离有效结构。
- `environment_mismatch`：个股证据尚可，但市场或板块环境与假设冲突。
- `execution_deviation`：事后移动标准、改变周期、摊平亏损或情绪化重进。

系统评价不只看胜率，还应观察期望值、平均盈利与平均亏损、MFE、MAE、MFE 利用率、重评贡献、规则合规率，以及不同市场环境和 setup 类型的表现。

这些指标只有在存在真实、带时间戳的历史记录时才能计算。没有记录时必须标记为 `unavailable`，不得估算。

## 术语表

| 中文 | 机器字段 | 含义 |
|---|---|---|
| 主判断 | `main_judgment` | 对当前 setup 质量的最终倾向 |
| 工作流状态 | `workflow_state` | 研究或用户明确提供的持仓上下文 |
| 相对强度 | `relative_strength_vs_benchmark` | 个股相对市场或板块基准的表现 |
| 结构失效 | `setup_invalidation` | 本次价格结构或时点失效 |
| 趋势失效 | `trend_invalidation` | 中期趋势假设失效 |
| 逻辑证伪 | `thesis_invalidation` | 基本面或催化逻辑被事实推翻 |
| 升级条件 | `upgrade_conditions` | 提高关注等级需要的新证据 |
| 数据缺口 | `data_gaps` | 当前无法获得或无法核实的证据 |
